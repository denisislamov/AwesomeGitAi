# Подключение IDE или другого MCP harness

Откройте репозиторий в AwesomeGitAi, затем нажмите **Подключить MCP**. Приложение проверит локальный host и выдаст `mcpServers` JSON с реальными абсолютными путями. Добавьте command/args в конфигурацию MCP вашего клиента. Секрет в этот JSON не включается; gateway хранит repository grant в приватном профиле вне репозитория.

В текущем MVP поддержаны stdio и опциональный loopback Streamable HTTP. Настройка HTTP и требования к token-файлу описаны в [README gateway](../../crates/mcp/README.md). Не размещайте token в репозитории или URL. Приложение должно оставаться открытым.

Первый вызов — `integration_guide` с `{"schema_version":1}`. Он доступен даже клиентам без поддержки resources/prompts. Полученные scope и generation обязательны; не копируйте синтетические UUID из примеров. Инструкцию из окна подключения или [полный bootstrap](agent-bootstrap.md) можно добавить к правилам проекта, сохранив существующие правила.

Проверены два независимых тестовых harness (Rust MCP SDK и raw Python JSON-RPC), каждый с обоими транспортами. Настройки и поведение конкретных версий Rider AI Assistant/Cursor пока не проверены: этот документ не обещает наличие определённого пункта меню в вашей версии IDE. Публичные схемы не привязывают приложение к бренду harness.
