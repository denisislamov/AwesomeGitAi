- Related changes are confirmed changed target lines intersecting a declaration/reference in the immutable comparison. Only files captured on both sides can supply this evidence; missing scope is unknown. These are source changes, not a count of affected behaviors.

- All successful analysis currently reports Partial. Unsupported languages, missing runtimes and malformed output do not become a numeric zero.

## Source guarantees and limits

Original captured files remain unchanged. Exact commit expansion is tied to its OID. Additional working-tree sources require matching original generation; dirty/untracked contents must be covered by its fingerprint. Additional clean files use the index baseline pinned by that generation, explicitly disclosed in the report, rather than claiming to reconstruct historical raw worktree bytes. Assume-unchanged and skip-worktree additions are excluded. Divergent old snapshots retain their original scope.

Host bounds: 128 files, 4 MiB serialized source input, 15-second subprocess deadline, 2 MiB output, eight cached immutable reports. Analyzer processes use private temporary working directories and sanitized environments. Returned paths, UTF-16 locations, IDs and strings are validated against captured files, and snippets are regenerated by the host. User projects, plugins, generators and source code are not executed.

C#/Roslyn and Node/TypeScript runtimes are bundled for the build Mac architecture; TypeScript service is pinned to 6.0.3. Jedi0.20.1/Parso0.8.7 dependencies are bundled, but Python's framework interpreter remains an explicit machine prerequisite and the launcher reports Unavailable when absent. Python dynamic dispatch, overrides and interfaces are not claimed. See [adapter setup/support](../../packages/relations/README.md).
