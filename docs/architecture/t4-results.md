# T4 and IDE layout — macOS implementation evidence

2026-10-30. Baseline `a3f0167` (final native T3 Quit check). Development build, not a signed release. Android/Windows/iOS remain deferred by the user.

## Delivered

- Official Rust MCP SDK rmcp 3.8.0, stdio and opt-in loopback Streamable HTTP. Nine tools; self-contained input schemas; tools-only guide plus prompt/resource. HTTP bearer credentials are separate from repository grants, UID-owned 0600, with Host/Origin checks. T6 trace/diagram tools are not advertised.
- Host-authenticated repository/worktree grants; agent-only domain boundary; selected pre-session working bytes preserve existing human edits. Up to 64 selected paths per session; changing that set requires another session. Snapshot exclusions and capture size limits remain explicit.
- SQLite schema 3 documents, atomic CAS updates and operation receipts, immutable predecessor history, scoped decision FTS. Newer explanation revisions preserve their predecessor. Retry uses the same key and semantic payload; request ID may change. Context is path-filtered, task-FTS-prioritized, bounded by content characters, with cursor digest checks and explicit truncation. Metadata is additional to the content budget.
- Explanation cards and code gutter markers use immutable anchors. Other snapshot IDs are labelled Relocated/Stale/Ambiguous/Missing; same-looking code never silently receives Exact or human acceptance. Full multi-file snapshots retain identity when one file is displayed. Human Viewed/Accepted/Question is a separate local-user route bound to both original snapshot IDs, never Git staging.
- Evidence stays `agent_reported`; no runner execution is claimed. Missing alternatives/checks remain missing. The coverage denominator counts changed lines on both diff sides; only exact current-pair anchors count. Requests are copied, never automatically sent to another agent.
- Movable/resizable/hideable docking panels, keyboard placement menus, persisted split layout, separate native windows for Files/Code/Explanation/Git. Main window owns state; bounded child mailbox validates actions against current scope and selection. Native geometry is restored if visible on available monitors. Full app restart safely redocks panels; detaching again restores native coordinates.
- “Подключить MCP” verifies the local host and supplies generic command/args using the packaged binary and current repository plus an agent bootstrap instruction. MCP host must remain running.
- User-requested compact typography: Monaco at a shared 15px base with the existing scale control; normal controls/body/metadata share that size, headings differ slightly. Line height 1.35–1.4; compact toolbars, paragraphs and cards. Both native and docked panels use the same tokens.

## Verification

- Workspace Rust: 73 distinct tests (plus a child invocation of the existing crash fixture). Client: 32 tests; editor probe: 4; native Rust: 8. Contracts/typecheck/build pass.
- Two independently implemented MCP harnesses: official Rust SDK client and raw Python JSON-RPC client. Both execute the real host workflow over both stdio and Streamable HTTP. Session → edit → capture → decision/evidence → supersede → close; no direct database fixture writes. Python additionally verifies desktop human-review persistence. These are recorded substitutes for Rider/Cursor product acceptance, not proof those products have been tested.
- Playwright: real repository behavior, three viewport widths, read-only keyboard access, cached file switching, historical/deleted files, snapshot comparisons and real MCP two-file session → gutter marker → original pair → human review. Eight functional scenarios pass. The 100k graph performance scenario passes both in an isolated run and the final sequential nine-test suite: final sequential full-suite startup samples 2335/1921/1845/1842/1842ms, hot 1493/1476/1445/1447/1452ms. Initial concurrent regression had one hot sample at 2499ms (over 2000ms); this contention-sensitive result is retained rather than hidden. Final cached 1900-line switch was 15ms. All nine Playwright scenarios pass.
- Packaged macOS native: actual bundled MCP generated a two-file-session explanation in a disposable repository. UI showed relocated/current distinction, opened original version and accepted a local-user review from a detached Explanation window. Review remained visible after redocking. Detached Code search survived multiple host polls. Native zoom changed size and geometry was saved. Cmd+Q with a detached Code window stopped the owned host (socket refused connections).
- Fresh final reviewer found two important integration issues: multi-file original comparison rejected and detached editor identity reset on polling. Both reproduced by failing regressions, fixed and passing. Minor popover override fixed. No second review cycle.

## Explicit limits

Physical second-monitor placement/disconnection was not manually exercised; geometry visibility fallback has unit coverage. Actual Rider AI Assistant and Cursor setup remains untested. Open-protocol compatibility does not force any harness to emit explanations. New grants do not authorize Git mutation or runner execution.

Context retrieval is conservative file/FTS relevance, not semantic dependency analysis (later tasks). Automatic recovery of detached windows after full restart is deliberately absent. Git Log local search/base selection can still reset when its component is moved/remounted; this earlier minor limitation remains tracked. Read-only native functionality is delivered; Git mutations start at T5. Release signing/installer/update/recovery acceptance remains T10.

Final compact-build follow-up: all nine browser tests pass and bundled MCP works against a temporary repository. Reopening a repository in Documents after rebuilding the unsigned app triggered `GIT_LIMIT_EXCEEDED`; process sampling found Git waiting in getcwd/open, and macOS TCC logs explicitly reported a changed code requirement and a new Documents permission prompt. This is not resolved by increasing Git's timeout. User was asked to approve the OS prompt. The Mac then locked, blocking the final compact-build visual inspection. Earlier native window/review/Quit evidence above remains valid; final-build Documents access requires the OS permission again. Signed distribution is a later release task.
