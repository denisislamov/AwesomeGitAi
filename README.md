# AwesomeGitAi

Проект кроссплатформенного Git-клиента с объяснениями решений рядом с кодом, памятью работы агентов и обязательным открытым MCP-интерфейсом.

Планируемые клиенты: desktop и Android/iOS companion с удалённым доступом к host. Стек: React + TypeScript + Tauri 2, Rust, SQLite.

Статус: реализованы T1 и T2 для macOS — host/IPC, хранилище событий и снимков, чтение Git и привязка объяснений к версиям кода. Проверки и ограничения: [отчёт T2](docs/architecture/t2-results.md). Добавлен desktop-интерфейс T3: код/diff, файлы, Git Log и карточка контекста. [Запуск и проверки T3](docs/architecture/t3-results.md). MCP-сервер (T4) и Git-записи (T5) ещё впереди. Интерактивный макет использует демонстрационные данные и не выполняет Git-команды или код проекта.

В макете работают выбор объяснения, панель/карточки, просмотр удалённых строк, переход между связанными файлами, отметки ревью и демонстрация staging, пошаговый успешный/отказной сценарий, диаграмма, история, память и граф. Основной файл показан только для чтения. Схема и результаты проверок — примеры, не данные реального проекта.

Версия UX 0.2: Git Log постоянно виден под кодом, как нижнее инструментальное окно Rider. Слева Local/Remote, в центре связный граф коммитов, справа файлы и сведения выбранной записи. Работают фильтрация веток, выбор коммита, сворачивание и разворачивание панели. Выбор в истории не меняет рабочий файл и ветку.

Проверено в браузере 29 октября 2026 года: основные переходы, оба сценария, независимость отметки ревью от staging, desktop-компоновка и узкое окно. Полный Git, MCP, реальный debugger и автоматическая генерация объяснений ещё не реализованы. UX не прошёл пользовательское исследование; план такого исследования находится в обзоре.

Версия UX 0.3: Gruvbox Dark Hard по умолчанию, насыщенные цвета C#-токенов. Учебный разбор показывает объяснение текущего шага, типизированные переменные с дельтами, выбранный кадр стека, наблюдение, вход/выход из TrySpend и итоговый снимок. Это симуляция на фиксированных данных.

Для UX 0.3 проверены в браузере вход/выход из метода, выбор кадра без продвижения, обход вызова, дельта ресурса 30 → 10, итог обоих сценариев, сохранение Git Log и переход обратно к карточкам. Проверена компоновка при ширине 1024 и 390 px; ошибок JavaScript в проверенных переходах не обнаружено.

Версия UX 0.4: Monaco во всём интерфейсе, основной текст 15 px, код 14 px и подписи от 12 px. Если шрифт отсутствует, используется системный моноширинный fallback. MCP обязателен по stdio и Streamable HTTP; инструкция, JSON Schema и примеры подготовлены, сервер ещё не реализован.

Для UX 0.4 проверены Monaco/размеры текста, переход из симуляции к объяснениям и компоновка при ширине окна 1024 и 390 px. Все 11 примеров MCP проходят JSON Schema Draft 2020-12 с проверкой форматов; неверная версия, неизвестные поля и отсутствие idempotency key в write-запросах отклоняются. Семантический валидатор и совместимость с реальными harness ещё требуют реализации и проверки.
